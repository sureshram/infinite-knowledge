What is a derivative?
The derivative f′(x) is the slope of the tangent line at x — the instantaneous rate of change. It is the limit of rise over run as the run shrinks to zero:
f′(x) = limh→0 [f(x+h) − f(x)] / h
Enable Rise / run triangle above to see this geometrically.
💡 Insight
Select a function and drag the slider. Watch where f′(x) = 0 — those are turning points. Where f′(x) > 0 the function rises; where f′(x) < 0 it falls.
